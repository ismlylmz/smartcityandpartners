# EyeOnBlue - ChildShield Demo (UNICEF Climate & Health 2026)

This repository contains the open-source demo module proposed for the **UNICEF Climate and Health 2026** application. It serves as a proof-of-concept for monitoring climate-driven health risks specifically tailored for children's well-being.

## 📌 Project Overview
**ChildShield** is a specialized sub-module developed by the technical team at **Smart City and Partners (SCP)**. It leverages Remote Sensing (RS) and Geographic Information Systems (GIS) to analyze environmental stressors such as extreme heat waves, drought, and flood risks that directly impact child health and nutrition.

## 🛠 Technical Scope
This demo repository focuses on:
- **Climate Indicator Templates:** Simplified logic for tracking NDVI, precipitation anomalies, and heat indices.
- **Explainable AI (XAI) Integration:** Frameworks for using SHAP (SHapley Additive exPlanations) to interpret climate model decisions in a transparent way.
- **Open Data Standards:** Compliance with Horizon Europe project standards for open-source scientific development.

> **Note:** This repository is a functional demo for evaluation purposes. It does **not** include EyeOnBlue’s proprietary commercial platform, production-grade infrastructure, private client data, or advanced real-time sensor integrations.

## 🚀 Development Roadmap
To ensure the "Open Source" commitment to UNICEF, the following milestones are planned:
- **Phase 1 (Q3 2026):** Release of standardized environmental indicator scripts for pilot regions.
- **Phase 2 (Q4 2026):** Community-driven dashboard templates for local healthcare providers.
- **Phase 3 (Ongoing):** Integration of drought and fire susceptibility modeling (e.g., FAO-56 Penman-Monteith method applications).
